# FuturByte Website Clone

## 📋 Overview

A responsive recreation of the **FuturByte** website, built with HTML, Bootstrap, and minimal CSS. This project demonstrates clean web development practices while maintaining simplicity and performance without heavy JavaScript dependencies.

FuturByte is a leading custom software development company that delivers cutting-edge digital solutions. This clone captures the essence of their professional online presence.

## 🛠️ Tech Stack

- **HTML5** - Semantic markup and structure
- **Bootstrap 4/5** - Responsive framework and UI components
- **CSS3** - Minimal custom styling
- **Bootstrap JS** - Interactive components only (navbar, dropdowns)

## 🎯 Development Approach

- **Bootstrap-First**: Leveraging Bootstrap's built-in classes for styling
- **Minimal Custom CSS**: Only adding CSS where Bootstrap falls short
- **No JavaScript Logic**: Relying solely on Bootstrap's native components
- **Fully Responsive**: Seamless experience across all devices
